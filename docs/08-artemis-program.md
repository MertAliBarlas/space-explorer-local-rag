# Artemis Program
The Artemis program is a United States-led international human spaceflight program. Its primary goal is to return humans to the Moon, specifically the lunar south pole, and build a sustainable presence there to prepare for future missions to Mars. Unlike the Apollo missions which were short visits, Artemis aims for long-term exploration.
